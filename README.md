# Arcadia — Sistem Manajemen Aset Mesin Arcade

Aplikasi web untuk mengelola inventaris mesin arcade: kategori, mesin, log perawatan, dan catatan pendapatan per mesin. Dibangun dengan Laravel, MySQL, Blade, Tailwind CSS, dan Vite.
